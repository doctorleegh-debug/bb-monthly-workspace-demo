# Beauty Blossom monthly workspace preview

보고용 월별 캘린더 / 업무 목록 UI 초안. GitHub Pages에서 실행되는 독립적인 정적 프로토타입입니다. Litpage 전체 앱이나 운영용 공동 편집 서버가 아닙니다.

- 월·날짜·담당자·파트·상태 필터, 목록/보드, 일정/업무 추가 및 수정, 월간 인쇄
- AES-256-GCM + PBKDF2-SHA256(310,000)으로 암호화한 기준 자료
- 암호를 가진 열람자는 자료를 복호화할 수 있습니다. 계정별 접근 통제나 권한 회수가 있는 시스템은 아닙니다.
- 변경사항은 브라우저에 암호화하여 저장됩니다. 사용자 간 실시간 동기화 및 원본 시트 자동 갱신은 없습니다.
- 외부 CDN / 분석 추적 / AI API 사용 없음
- 공개 배포 폴더에는 원본 시트, 실명 평문, 열람 암호를 포함하지 않습니다.

디자인과 SVG 아이콘은 본 초안을 위해 제작했습니다. 기능 검토 대상 원본 프로젝트: https://github.com/litmers-dev/litpage

운영 도입 시 별도 서버, 로그인·승인, 접근 권한, 공동 데이터 저장 및 백업을 구현하고 검증해야 합니다.
