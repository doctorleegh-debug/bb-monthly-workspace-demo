초안의 저장 방식

수정 내용은 현재 브라우저에 암호화하여 저장됩니다. 다른 사람이나 다른 기기에 실시간으로 전달되지 않으며, 원본 Google 시트에도 반영되지 않습니다. 「백업」으로 암호화된 파일을 내려받아 같은 암호로 「불러오기」 할 수 있습니다. 가져온 파일은 현재 초안 데이터를 대체합니다.

실제 운영 버전에 필요한 작업

직원 로그인·관리자 승인, 공용 데이터 저장, 권한별 열람, 동시 편집과 변경 이력, 서버 백업을 연결합니다. 운영 환경과 비용은 이 초안 검토 후 확정합니다.

이 화면은 Litpage 도입을 검토하기 위한 별도의 맞춤 UI 초안입니다. Litpage 전체 기능이 설치된 서비스는 아닙니다. 2026년 11·12월 시트의 입력 내용을 기준으로 구성했으며, 원본의 빈 상태는 ‘미지정’으로 표시합니다.
